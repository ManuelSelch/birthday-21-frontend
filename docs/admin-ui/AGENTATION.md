# Agentation

- Sign in as an admin and use the pen icon on the guests page to enable or disable annotations. The preference starts off and lasts for the browser tab session or until logout.
- The toolbar is available across the site while enabled and the admin session is valid. Authentication is checked server-side; the browser preference does not grant access.
- Annotations may contain page content, including guest information. Review them before sharing. Agentation uses its local copy-and-paste workflow; no MCP endpoint is configured by the application.
